تقرير المشروع — نظام إدارة المصانع

المشروع: factory-management-system · الإصدار: 1.0.0 · التاريخ: مايو 2026

1. ملخص تنفيذي

نظام ERP لإدارة المصانع يوفّر واجهة ويب مع واجهة برمجة تطبيقات REST مبنية على Node.js وPostgreSQL. التطبيق متعدد المصانع (عزل البيانات عبر factory_id) مع مستوى إداري للمنصة لإدارة المصانع والاشتراكات.

2. التقنيات

الطبقةالتقنية
الخادمNode.js، Express 4، Sequelize 6، PostgreSQL
الأمانJWT، bcrypt، Helmet، CORS، express-validator
الواجهةReact 18، Vite 5، React Router 6، Tailwind CSS
الحالةZustand (تخزين الجلسة محلياً)
الترجمةi18next (عربي / إنجليزي)

3. هيكل المستودع

  • src/ — الخلفية: server، app، controllers، services، models، routes، middleware، validations، config
  • frontend/src/ — الواجهة: pages، services، router، store، i18n، Design System

تشغيل التطوير: من جذر المشروع npm run dev:all (API غالباً على المنفذ 3000، Vite على 5173).

4. الوحدات الوظيفية

4.1 المصادقة والمستخدمون

تسجيل الدخول بالبريد وكلمة المرور؛ JWT؛ أدوار مصنعية (صاحب مصنع، موارد بشرية، مخزون، إنتاج، مبيعات)؛ إدارة المستخدمين وحدود الاشتراك.

4.2 لوحة الإدارة (Admin)

إدارة المصانع والاشتراكات والمستخدمين على مستوى المنصة.

4.3 المخزون والمشتريات

مواد خام، شراء متعدد المستويات، متوسط تكلفة مرجح، سجل مشتريات، ملخص كميات حسب نوع الوحدة.

4.4 المنتجات والإنتاج

منتجات، وصفات، دفعات إنتاج مع تكاليف.

4.5 المبيعات

عملاء، طلبات، بنود الطلبات.

4.6 الموارد البشرية

أقسام، موظفون، حضور، قفل فترات، تقارير رواتب.

4.7 المالية والمصاريف التشغيلية

تقارير مالية، رأس مال، قائمة مالية؛ مصاريف تشغيلية وميزانيات.

4.8 الكاش فان

مركبات، تحميل وتنزيل، مخزون ميداني، مبيعات، مدفوعات، تسوية وجرد.

4.9 التقارير

تقارير مجمّعة للمخزون والإنتاج والمبيعات والربحية والموارد البشرية عبر /reports.

6. الأمان والصلاحيات

JWT؛ التحكم بالأدوار؛ اشتراك المصنع؛ تشفير كلمات المرور؛ عدم إرجاع الأسرار في الاستجابات.

7. قاعدة البيانات

PostgreSQL عبر Sequelize؛ أوامر مساعدة: db:migrate، db:seed، db:reset.

8. الواجهة الأمامية

توجيه حسب الدور؛ دعم الوضع الداكن؛ ترجمة؛ إعدادات الحساب (بريد، كلمة مرور، اسم المصنع لصاحب المصنع).

9. خلاصة

منصّة متكاملة لإدارة العمليات الصناعية والميدانية مع فصل طبقي واضح. للإنتاج: ضبط .env، النسخ الاحتياطي، ومراقبة الأداء.

ملحق: أوامر سريعة

npm run dev          # API فقط
npm run dev:all      # API + واجهة Vite
npm start            # تشغيل Node إنتاج
cd frontend && npm run build
