# تقرير المشروع — نظام إدارة المصانع

<p class="meta"><strong>المشروع:</strong> factory-management-system · <strong>الإصدار:</strong> 1.0.0 · <strong>التاريخ:</strong> مايو 2026</p>

## 1. ملخص تنفيذي

نظام **ERP لإدارة المصانع** يوفّر واجهة ويب حديثة مع واجهة برمجة تطبيقات (REST) مبنية على **Node.js** و**PostgreSQL**. التطبيق متعدد المصانع (كل مصنع له بيانات معزولة عبر `factory_id`) مع مستوى إداري للمنصة لإدارة المصانع والاشتراكات.

---

## 2. التقنيات

| الطبقة | التقنية |
|--------|---------|
| الخادم | Node.js، Express 4، Sequelize 6، PostgreSQL |
| الأمان | JWT، bcrypt، Helmet، CORS، express-validator |
| الواجهة | React 18، Vite 5، React Router 6، Tailwind CSS |
| الحالة | Zustand (تخزين الجلسة محلياً) |
| الترجمة | i18next (عربي / إنجليزي) |
| الرسوم البيانية | Recharts |
| التصدير | jsPDF، html2canvas (حسب الصفحات) |
| التطوير | nodemon، concurrently (`npm run dev:all`) |

---

## 3. هيكل المستودع

- **`src/`** — الخلفية: `server.js`, `app.js`, `controllers`, `services`, `models`, `routes`, `middleware`, `validations`, `config`
- **`frontend/src/`** — الواجهة: `pages`, `services`, `router`, `store`, `i18n`, مكوّنات التصميم (Design System)

**تشغيل التطوير:** من جذر المشروع `npm run dev:all` (API غالباً على المنفذ 3000، Vite على 5173).

---

## 4. الوحدات الوظيفية

### 4.1 المصادقة والمستخدمون

تسجيل الدخول بالبريد وكلمة المرور؛ JWT؛ أدوار مصنعية: صاحب مصنع، مدير موارد بشرية، مخزون، إنتاج، مبيعات؛ إدارة مستخدمي المصنع وحدود الاشتراك.

### 4.2 لوحة الإدارة (Admin)

إدارة المصانع، الاشتراكات، والمستخدمين على مستوى المنصة.

### 4.3 المخزون والمشتريات

مواد خام بوحدات متعددة، شراء متعدد المستويات، متوسط تكلفة مرجح، سجل مشتريات، تعديل الكميات، ملخص كميات حسب نوع الوحدة في لوحة المخزون.

### 4.4 المنتجات والإنتاج

منتجات، وصفات إنتاج، مدخلات ومخرجات، دفعات إنتاج مع تكاليف.

### 4.5 المبيعات

عملاء، طلبات مبيعات، بنود الطلبات.

### 4.6 الموارد البشرية

أقسام، موظفون، حضور، قفل فترات، تقارير رواتب.

### 4.7 المالية والمصاريف التشغيلية

تقارير مالية، رأس مال، قائمة مالية؛ مصاريف تشغيلية وميزانيات (`OperationalExpense`, `ExpenseBudget`).

### 4.8 الكاش فان (Cash Van)

مركبات، تعيينات، تحميل وتنزيل، مخزون الميدان، مبيعات POS ميدانية، مدفوعات، تسوية وجرد.

### 4.9 التقارير

تقارير مجمّعة: مخزون، إنتاج، مبيعات، ربحية، موارد بشرية، وغيرها عبر مسار `/reports`.

---

## 5. واجهة البرمجة (API)

المسارات تحت **`/api/v1`** (حسب إعداد التطبيق). أهم التجميعات:

| المسار | الغرض |
|--------|--------|
| `/health` | صحة الخدمة |
| `/auth` | المصادقة، الملف الشخصي، تغيير كلمة المرور والبريد واسم المصنع |
| `/admin` | إدارة المنصة والمصانع |
| `/users` | مستخدمو المصنع |
| `/inventory` | المواد والمشتريات |
| `/products` | المنتجات |
| `/production` | الوصفات والدفعات |
| `/sales` | العملاء والطلبات |
| `/reports` | التقارير |
| `/hr` | الموارد البشرية |
| `/cash-van` | الكاش فان (عدة مسارات فرعية) |
| `/operational-expenses` | المصاريف التشغيلية |

---

## 6. الأمان والصلاحيات

- التحقق من JWT؛ حساب مدير النظام عبر متغيرات البيئة عند الحاجة.
- التحكم بالأدوار على المسارات.
- مراقبة حالة اشتراك المصنع وتوجيه المستخدم عند الانتهاء.
- تشفير كلمات المرور؛ عدم إرجاع كلمات المرور في الاستجابات.

---

## 7. قاعدة البيانات

PostgreSQL عبر Sequelize؛ جداول للمصانع، المستخدمين، المواد، المشتريات، المنتجات، الوصفات، الدفعات، العملاء، الطلبات، الموظفين، الحضور، كيانات الكاش فان، المصاريف التشغيلية، وغيرها. أوامر مساعدة: `db:migrate`, `db:seed`, `db:reset`.

---

## 8. الواجهة الأمامية

توجيه حسب الدور؛ تصميم موحّد؛ دعم الوضع الداكن؛ إعدادات حساب (بريد، كلمة مرور، اسم المصنع لصاحب المصنع)؛ واجهة عربية وإنجليزية.

---

## 9. خلاصة

المشروع يقدّم منصّة متكاملة لإدارة العمليات الصناعية والميدانية مع فصل واضح بين الطبقات وقابلية التوسع. للإنتاج يُنصح بضبط متغيرات البيئة، النسخ الاحتياطي لقاعدة البيانات، ومراجعة أداء حزمة الواجهة عند الحاجة.

## ملحق: الأوامر السريعة

```bash
npm run dev          # خادم API فقط
npm run dev:all      # API + واجهة Vite
npm start            # تشغيل الإنتاج (Node)
cd frontend && npm run build
```

**متطلبات:** Node.js، PostgreSQL، ملف `.env` لإعدادات الاتصال و JWT ومدير النظام.
